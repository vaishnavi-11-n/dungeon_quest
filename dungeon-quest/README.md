# 🐉 Dungeon Quest — Python Adventure Game

A dungeon adventure game built with Python and Tkinter. Explore dangerous encounters, battle enemies, collect coins, upgrade equipment, and try to survive the dungeon!

## 🎮 Features

- **Graphical User Interface:** A desktop interface built using Python Tkinter.
- **Multiple Enemies:** Fight different enemies as you progress through the dungeon.
- **Turn-Based Combat:** Attack enemies, defend yourself, and use potions.
- **Difficulty Levels:** Choose a difficulty that suits your play style.
- **Coins and Rewards:** Earn coins through battles.
- **Shop and Inventory:** Purchase useful items and manage your equipment.
- **Equipment Upgrades:** Improve your weapons and armor.
- **Save and Continue:** Save your progress locally.
- **High Scores:** Keep track of your best scores.
- **Achievements:** Work towards in-game achievements.

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- Random module

## 💻 Requirements

- Python 3.10 or later recommended
- Tkinter (usually included with standard Python installations)

No additional Python packages are normally required.

## 🚀 How to Run

1. Install Python from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the integrated terminal.
5. Run your Python game file:

   ```bash
   python "YOUR_GAME_FILENAME.py"
   ```

   Replace `YOUR_GAME_FILENAME.py` with your actual Python filename.
